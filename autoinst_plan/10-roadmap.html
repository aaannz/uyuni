Phase 1 — Unified kernel options (G0)

Builder hierarchy, factory routing, and the catalogue of legacy strings to reproduce live in 20-kernel-options.md — read it before starting any step here.

Step 1.1 — Port builder hierarchy (status: DONE 2026-10-08)

  • Implemented per 20-kernel-options.md §2–§4 and the step design in 30-step-1.1-builders.md: interface, abstract base (configurable serverFqdn, optional User context), factory, builders Rhel / AutoYast / Agama under com.suse.manager.autoinstallation.{builder,installer}; no Debian builder (no debian/ubuntu install type exists — unroutable dead code, decision recorded in the step design §1.3).
  • SLE16 baseline (00-goals.md §5.1): opensuse16.1 install type, cobbler breed suse, http:// URLs; factory routes isSLES16OrGreater() → Agama before the SUSE branch; routing is install-type-only — unknown types throw KernelOptionsBuilderException, no breed-based fallback.
  • distroOptions idempotent (setOptionIfNotPresent) — results are persisted and recomputed on tree create/edit.
  • profileOptions stays in the contract but is empty until the Cobbler exit (G6): cobbler’s tftpgen owns the installer-selection option on PXE entries (step design §1.4).
  • 34 DB-free unit tests; compile + checkstyle clean.

Step 1.2 — Distro path (status: DONE 2026-10-08)

  • Implemented per 40-step-1.2-distro-path.md: BaseTreeEditOperation#applyDistroKernelOptions() merges KernelOptionsBuilder.distroOptions into the tree’s options (user-typed options win) and runs on create and edit via BaseTreeEditOperation#store — fixing the XML-RPC kickstart.tree.update option-wipe; blank serverName falls back to ConfigDefaults.getJavaHostname(). TreeCreateOperation keeps only the duplicate-label check.
  • Preserve: persistence into KickstartableTree.kernelOptions(_post) (kernelOptionsPost untouched); user-scoped installer-updates channel lookup (§5.5); the useonlinerepo flag survives round-trips (decision 00-goals.md §5.8).
  • On the way: step-1.1 defect repaired (RHEL systemOptions emitted inst.ks= instead of the spec/legacy ks=); test fixture gap fixed (TreeOperationTestBase now also creates the SUSE loader kernel/initrd layout — SUSE-type store() used to fail validation).
  • Verified on the agent VM (dedicated pgsql-4eclipse container after mgradm stop; branch schema incl. opensuse16.1): 57 tests green, full-core checkstyle audit clean. PXE E2E matrix stays with step 1.7.

Step 1.3 — System path (status: NOT STARTED)

  • KickstartScheduleCommand#getExtraOptions continues to produce the user part (ksdevice= + custom options) for now (full resolution in step 2.6).

Step 1.4 — Initiate path (status: NOT STARTED)

  • Replace KickstartInitiateAction#buildKernelOptions and the hand-rolled map serializer per 20-kernel-options.md §5.3: feed resolved cobbler options into KernelOptionsList, shared SUSE text→textmode helper (added here — first caller), compose via the builder’s systemOptions, keep info= (nopxe URL) behavior.
  • Drop the dead debian/ubuntu branch (no debian/ubuntu install type exists) and the rhel6 kssendmac branch (compat dropped — always inst.ks.sendmac).
  • Route SLE16 by install type (tree resolved from the cobbler distro name in prepareCobblerBoot) — breed is suse for both SLES15 and SLE16.

Step 1.5 — Profile path (status: NOT STARTED)
